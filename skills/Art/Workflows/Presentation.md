# Presentation Workflow

Generate graphics for presentations, slides, and talks.

## When to Use

- User asks for "presentation graphics", "slide images", "talk visuals"
- Creating slides for technical presentations
- Need consistent visual theme for deck

## Process

1. **Understand Context**
   - What's the presentation about?
   - How many slides/graphics needed?
   - Slide dimensions (usually 1920x1080, 16:9)
   - Presentation style (technical, business, creative)

2. **Plan Visual Strategy**
   - Title slide: Hero image with title space
   - Section headers: Themed dividers
   - Concept slides: Illustrations or diagrams
   - Technical slides: Architecture/flow diagrams
   - Closing slide: Call-to-action or summary visual

3. **Maintain Consistency**
   - Use same aesthetic across all slides
   - Consistent color palette
   - Matching style and mood
   - Branded look and feel

4. **Generate Each Type**

   **Title Slide:**
   - Bold, attention-grabbing
   - Leave space for title text
   - Set the tone for presentation

   **Section Headers:**
   - Simpler than title
   - Visual transition between topics
   - Thematic consistency

   **Content Visuals:**
   - Support the message
   - Don't overwhelm text
   - Clear and focused

   **Technical Diagrams:**
   - Use Mermaid or generated diagrams
   - Clean, professional style
   - High contrast for projectors

5. **Standard Dimensions**
   - **16:9 (Standard)**: 1920x1080
   - **4:3 (Legacy)**: 1024x768
   - **Ultrawide**: 2560x1080

6. **Save Organization**
   ```
   ~/Downloads/presentation-[topic]/
   ├── 01-title-slide.png
   ├── 02-intro.png
   ├── 03-section-1-header.png
   ├── 04-architecture-diagram.png
   └── ...
   ```

## Example: Tech Talk on WebAssembly

**Slides Needed:**
1. Title slide - "WebAssembly: The Future of Web Performance"
2. Section: "What is WebAssembly?"
3. Diagram: "WASM Architecture"
4. Section: "Performance Benefits"
5. Diagram: "Execution Flow"
6. Closing slide

**For each slide:**
- Generate via Nano Banana Pro
- Apply technical aesthetic
- 1920x1080 dimensions
- High contrast for projection
- Save to organized folder

## Tips

- **Test on projector**: Colors may look different
- **High contrast**: Essential for visibility
- **Minimal text in images**: Let slides have text
- **Consistent theme**: All slides feel cohesive
- **Sign discreetly**: Small Skippy signature in corner
