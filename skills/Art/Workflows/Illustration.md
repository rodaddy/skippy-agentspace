# Illustration Workflow

Generate conceptual illustrations and artistic visualizations.

## When to Use

- User asks to "illustrate [concept]", "visualize [idea]", "create art for [topic]"
- Need artistic representation of abstract concepts
- Want visual storytelling or metaphorical images

## Process

1. **Understand Concept**
   - What's the core idea or concept?
   - What message should the image convey?
   - Who's the audience?
   - What's the use case? (blog, presentation, social media)

2. **Simplify Complex Ideas**
   - Break down abstract concepts into visual metaphors
   - Identify 2-3 key elements to represent
   - Choose appropriate symbolism
   - Avoid overcomplication

3. **Load Aesthetic**
   - Read `../Aesthetic.md`
   - Apply color palette and style
   - Ensure brand consistency

4. **Build Prompt**
   ```
   Create an illustration representing [concept].

   Visual metaphor: [describe the metaphor]
   Key elements:
   - Element 1: [description]
   - Element 2: [description]
   - Element 3: [description]

   Composition: [layout description]

   Style: [from Aesthetic.md]
   Mood: [mood/feeling to convey]

   Technical: 4K, transparent background, signed by Skippy
   ```

5. **Generate via Nano Banana Pro**
   - Call Gemini 3 Pro Image API
   - Use high quality settings (4K)
   - Request transparent background if needed

6. **Save and Present**
   - Save to `~/Downloads/illustration-[concept]-[date].png`
   - Add "Generated by Skippy" signature
   - Show to user
   - Offer iterations if needed

## Example: "Illustrate distributed consensus"

**Concept:** Multiple nodes agreeing on a single value

**Visual Metaphor:**
- Circles (nodes) arranged in network pattern
- Lines connecting them
- Visual agreement/synchronization effect
- Center point of convergence

**Prompt:**
```
Create an illustration of distributed consensus in distributed systems.

Visual metaphor: Multiple interconnected nodes (glowing orbs) arranged
in a network pattern, with energy/light flowing between them, converging
on a central shared state represented by a bright focal point.

Composition: Circular arrangement of 5-7 nodes, connections forming
web pattern, central convergence point emphasized.

Style: Tokyo Night aesthetic
- Deep blue/purple background
- Neon cyan and magenta for nodes and connections
- Glowing effects for emphasis
- Clean, technical illustration style

Mood: Technical, harmonious, synchronized

Technical: 4K quality, transparent background
```

## Tips

- **Metaphors over literals**: Abstract concepts work better as metaphors
- **Keep it simple**: 2-3 key visual elements maximum
- **Consistent style**: Always apply aesthetic
- **Iterate**: First attempt might need refinement
- **Sign your work**: Add Skippy signature
