# BlogHeader Workflow

Generate blog header images using Nano Banana Pro with consistent aesthetic.

## When to Use

- User asks to "create a blog header", "make a header image", "article graphic"
- Need visual for blog post or article
- Want branded imagery for content

## Process

1. **Understand Content**
   - Get blog post title or topic
   - Understand key concept/message
   - Identify target platform (blog, Twitter, LinkedIn, etc.)

2. **Simplify Concept** (Optional but Recommended)
   - For complex topics, break down into simple visual elements
   - Identify 2-3 key visual metaphors
   - Avoid literal representations - aim for conceptual

3. **Load Aesthetic**
   - Read `../Aesthetic.md` for style parameters
   - Apply color palette, style, composition rules
   - Ensure consistency with brand

4. **Determine Dimensions**
   - **Blog**: 1200x630 (standard social sharing)
   - **Twitter header**: 1500x500
   - **LinkedIn**: 1200x627
   - **Custom**: Ask user or detect from context

5. **Generate Prompt**
   ```
   Create a [dimension] blog header image about [topic].

   Visual concept: [simplified concept description]

   Style: [Load from Aesthetic.md]
   - Color palette: [colors]
   - Aesthetic: [style description]
   - Mood: [mood]

   Technical requirements:
   - Transparent background (or specific background)
   - 4K quality
   - High contrast
   - Text-free (or include: "[title]")
   ```

6. **Call Nano Banana Pro**
   ```bash
   # Using Gemini API
   curl -X POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3-pro-image:generateImage \
     -H "Content-Type: application/json" \
     -H "x-goog-api-key: $GEMINI_API_KEY" \
     -d '{
       "prompt": "[full prompt from step 5]",
       "aspectRatio": "16:9",
       "outputOptions": {
         "mimeType": "image/png"
       }
     }'
   ```

   **Note**: Actual API call may vary - use proper SDK or API wrapper

7. **Save Image**
   - Initial save: `~/Downloads/header-[topic]-[date].png`
   - **Sign the image**: Add "Generated by Skippy" watermark/signature
   - Offer to save to specific project location

8. **Present to User**
   - Show image preview (if possible)
   - Provide file path
   - Ask if adjustments needed

## Example

**Input:** "Create a header for my blog post about WebAssembly performance"

**Process:**
1. Topic: WebAssembly performance
2. Visual concept: Fast execution, code transformation, speed
3. Load Tokyo Night aesthetic (or user's aesthetic)
4. Dimensions: 1200x630 (blog default)
5. Generate prompt:
   ```
   Create a 1200x630 blog header image about WebAssembly performance.

   Visual concept: Abstract representation of high-speed code execution,
   showing transformation from traditional code to optimized binary,
   emphasizing speed and efficiency with motion blur or speed lines.

   Style: Tokyo Night technical aesthetic
   - Deep blue/purple background
   - Neon accents in cyan and magenta
   - Clean, modern technical illustration
   - High contrast

   Technical: Transparent background, 4K quality, no text
   ```
6. Call Nano Banana Pro API
7. Save: `~/Downloads/header-webassembly-performance-20251229.png`
8. Sign with "Generated by Skippy"

## Tips

- **Simple is better**: Avoid overcomplicating visual concepts
- **Conceptual over literal**: Metaphors work better than direct representations
- **Test and iterate**: First attempt might not be perfect
- **Consistent branding**: Always apply aesthetic file
- **Sign your work**: Add Skippy signature to all generated images
